These pages describe short task-focused workflows. Use them when you already work with Irbis and want to find out how to do a specific operation.

Most step-by-step pages list prerequisites, the UI location, related next steps, and the task instructions.

**Workflow areas**

- [Data import and saving](../step-by-step/data-import/index.md): open raw data, open existing projects, and save processed data.
- [Planes processing](../step-by-step/planes/index.md): inspect, align, crop, preprocess, and manage planes data.
- [3D model processing](../step-by-step/model/index.md): create 3D models, correct drift, trace dendrites, separate spines, and export object results.
- [Tracks processing](../step-by-step/tracks/index.md): import, view, analyze, and categorize TrackMate tracks.
- [ResultsViewer](../step-by-step/results-viewer/index.md): explore generated data in tables and plots.
- [Viewport, animation, and shortcuts](../step-by-step/viewport/index.md): navigate the visualization panel, store views, and create animations.
