Track data can be uploaded as TrackMate `.xml` files.

!!! info "Before you start"
    **UI location:**

    - Main app: **Tracks** tab.

**Steps**

1. Press **Import tracks**.
2. In the file dialog, select the XML files to import.
3. To select multiple files, hold **Ctrl** while selecting them.
4. If multiple files are selected, enter the time points they belong to in the window that opens.

**Next steps**

- Continue to [View tracks](../step-by-step/tracks/view-tracks.md).
- Then [Calculate track parameters](../step-by-step/tracks/calculate-parameters.md).
