# Filter available data

!!! info "Before you start"
    **Prerequisites:**

    - Data opened in ResultsViewer.
    - Desired modality selected at the top of ResultsViewer: model, tracks, or points.
    - For model data, desired branch selected at the top of ResultsViewer.

    **UI location:**

    - ResultsViewer: **Filtering** panel on the left.

## Steps

1. Select the parameter to filter by from the drop-down menu.
2. For categorical parameters, select included categories in the checkbox list.
3. For numerical parameters, set the lower and upper filter range.
4. For numerical parameters, you can also set the range in the plot.
5. Press **Filter**.
6. Existing filters appear as state buttons in the **Filtering** panel.
7. Toggle a filter button off to disable the filter. Toggle it on to enable it again.
8. To delete a filter, select the parameter name from the drop-down menu and press **delete**.

Filters should sync with the main Irbis app. Changing a filter in Irbis updates ResultsViewer, and changing it in ResultsViewer updates Irbis.
