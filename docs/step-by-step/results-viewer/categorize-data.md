# Define ResultsViewer categorization

Irbis-generated data can be further categorized in ResultsViewer.

!!! info "Before you start"
    **Prerequisites:**

    - Data opened in ResultsViewer.
    - Desired modality selected at the top of ResultsViewer: model, tracks, or points.
    - For model data, desired branch selected at the top of ResultsViewer.

    **UI location:**

    - ResultsViewer: **Categorization** panel at the bottom right.

## Define a new categorization

1. In **Categorization**, press **Add new categorization**.
2. In the dialog, enter the categorization name in **Categorization name**.
3. Define categories by combining criteria.
4. Enter each category name in its text field.
5. Press **Add criteria** in a category section to add a rule.
6. Press **Add category** to add another category.
7. Press **Save categorization**.

## Use categorization templates

Templates are stored categorization rules that can be reused for multiple datasets. Templates are stored with Irbis and loaded in the **Template** drop-down menu.

1. To use an existing template, select it from **Template** and press **Use**.
2. To edit an existing template, select it and press **Edit**.
3. To create a template, press **Add a new template** and define it like a categorization.
4. To transfer templates between computers or users, press **Export templates** and later use **Import templates**.
5. To store an existing dataset categorization as a template, right-click the selected categorization in the parameter checkbox list on the left side of ResultsViewer.

!!! warning
    Filters and categorizations are synced between the main Irbis app and ResultsViewer, but generated data itself is not. If you change or generate data in the main app, close and reopen ResultsViewer to sync changes.
