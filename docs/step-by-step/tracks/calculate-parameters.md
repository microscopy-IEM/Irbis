# Calculate track parameters

!!! info "Before you start"
    **Prerequisites:**

    - TrackMate `.xml` data loaded in Irbis.

    **UI location:**

    - Main app: **Tracks** tab.

## Steps

1. Press **Calculate parameters**.
2. Wait for all implemented calculations to finish.

This step can take a while.

## Next steps

- Continue to [Define and edit track categorizations](categorize-tracks.md).
- Explore results in [ResultsViewer](../results-viewer/index.md).
