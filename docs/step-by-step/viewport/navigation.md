# Navigate the visualization panel

!!! info "Before you start"
    **UI location:**

    - Main visualization panel.
    - Bottom panel under the visualization panel.

## Mouse controls

- Hold right mouse button: rotate in 3D.
- Hold scroll wheel button: translate.
- Scroll wheel: zoom.
- Color wheel button: expand options for hiding or showing model parts and changing color and transparency settings.
- **Home**: reset axes view.

## Bottom panel

- Data-type checkboxes: show or hide currently present data types.
- **Reset**: reset the view, useful when zoom or rotation gets stuck.
- **Undo** and **Redo**: undo or redo supported steps.
- **Export figure**: export the current view into a separate window that can be saved.
- Plot icon button: open [ResultsViewer](../results-viewer/index.md).
