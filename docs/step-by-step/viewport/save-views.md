# Save views

Saved views store the rotation and zoom of the axes and the selection of visible elements. The current time point is not saved.

!!! info "Before you start"
    **Prerequisites:**

    - 3D model created.

    **UI location:**

    - Main app: **Viewport** tab, **View storing option** section.

## Save and use a view

1. Position the view as desired.
2. Select the components you want visible.
3. In **View storing option**, press **Store view**.
4. Double-click the saved view name in the listbox to apply it.
5. To rename a view, select it and press **Rename view**.
6. To delete a view, select it and press **Delete view**.

## Show only selected objects

1. Select the objects to keep visible by left-clicking them.
2. Use **Ctrl+click** to select multiple objects.
3. Use the show-only-selected option in **View storing option** to hide all other objects.
