# Export processed data as an .irbis file

Exporting data as an `.irbis` file lets you reopen the processed project in Irbis later.

!!! info "Before you start"
    **Prerequisites:**

    - Data loaded or processed in Irbis.

    **UI location:**

    - Main app: **Files** tab.

## Steps

1. If needed, fill in metadata in the **File info** section.
2. Press **Save as .irbis**.
3. Select the output folder.
4. Enter a file name.
5. Press **Save**.
