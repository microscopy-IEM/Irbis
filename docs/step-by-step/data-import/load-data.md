# Load data

!!! info "Before you start"
    **Prerequisites:**

    - Raw volumetric data, TrackMate tracks, or processed data in `.irbis` format.

    **UI location:**

    - Main app: **Files** tab.
    - Alternative raw-data tabs: **Planes**, **Points**, or **Tracks**.

## Steps

1. In the **Files** tab, press **New**.
2. Choose the data type: **Import planes**, **Import tracks**, or **Load .irbis structure**.
3. In the file dialog, select the file and press **Open**.

## Alternative: new raw data

1. For structural microscopy images supported by BioFormats, go to the **Planes** tab.
2. For SMLM data, go to the **Points** tab.
3. For TrackMate trajectory XML files, go to the **Tracks** tab.
4. Press **Import** at the bottom of the selected tab.
5. Select the data file and press **Open**.

## Alternative: existing Irbis data

1. Press **Load .irbis file**.
2. Select the `.irbis` file and open it.

If you repeatedly use files from the same folder:

1. Select the folder from the folder drop-down menu.
2. If the folder is missing, press **Add path** and select it.
3. Double-click the folder in the drop-down menu.
4. Double-click a file in the file list to load it.

## Next steps
