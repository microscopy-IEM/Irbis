# Preprocess planes

Preprocessing is applied only to the currently editable channel.

!!! info "Before you start"
    **Prerequisites:**

    - Planes data loaded in Irbis.
    - Editable channel selected in the **Planes** tab.

    **UI location:**

    - Main app: **Planes** tab, **Pre-processing** section.

## Steps

1. In **Pre-processing**, click the settings icon button.
2. In the preprocessing window, activate the methods you want to use by clicking their method buttons, such as **Spatial filter**.
3. If needed, change the order: select a method rectangle and move it with the arrows at the bottom of the tab.
4. Compare the original editable channel on the left with the adjusted data on the right.
5. When satisfied, press **Save settings**.
6. Enter a workflow name in the dialog.
7. Select the saved pipeline from the drop-down menu.
8. Press **Apply** to preprocess the editable channel.
9. To return to original data, press **Reset**.

Saved pipelines appear in the preprocessing window and in the main window **Filter set** drop-down menu.
