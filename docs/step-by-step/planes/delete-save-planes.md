# Delete or save planes data

Planes data are saved inside the `.irbis` file unless you delete them. You can also export planes as TIFF files.

!!! info "Before you start"
    **Prerequisites:**

    - Planes data loaded in Irbis.

    **UI location:**

    - Main app: **Planes** tab, bottom of the tab.

## Delete planes data

Use this after 3D reconstruction if you no longer need planes data and want to save space or improve performance.

1. Click **Delete planes**.
2. In the confirmation dialog, select **Yes**.
3. Alternatively, select **Yes, but keep copy as *.mat** to save a MATLAB-only copy.

## Save planes as TIFF

1. Click **Save planes as tif**.
2. Select the output folder.
3. Enter the file name.
