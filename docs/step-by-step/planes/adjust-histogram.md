# Adjust channel histogram

This changes only visualization. It does not change the raw data.

!!! info "Before you start"
    **Prerequisites:**

    - Planes data loaded in Irbis.

    **UI location:**

    - Main app: **Planes** tab, histogram controls at the bottom.

## Steps

1. Select the editable channel by clicking its channel-name button in **Channels**.
2. At the bottom of the tab, drag the edge of the colored rectangle to change the displayed range.
3. Press **Auto** to adjust the range automatically.
4. Press **Reset** to return to the default view.
