# Align planes across time points

!!! info "Before you start"
    **Prerequisites:**

    - Planes data loaded in Irbis.

    **UI location:**

    - Main app: **Planes** tab, **Pre-processing** section.

## Steps

1. In **Pre-processing**, click **Pre-register**.
2. Review the window showing the calculated shift between the first time point and each following time point.
3. Press **Accept** to apply the shifts.

Irbis shifts each time point and crops the hanging edges.
