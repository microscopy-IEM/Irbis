# Select objects and export results

Objects can be selected with a left click. When selected, the spine ID and group ID in brackets appear next to the object. Additional object information appears in green in the upper-left corner of the visualization panel.

!!! info "Before you start"
    **Prerequisites:**

    - 3D model created.

    **UI location:**

    - Main app: **Model** tab.
    - Visualization panel.

## Object visualization

1. Go to the object-type subtab you want to examine.
2. Expand **Object list**.
3. Select an object by clicking its number in the list, or by left-clicking it in the visualization panel.
4. Use the object list to check object IDs and group IDs.
5. Press **Plot time points** to open an external plot of object development over time.

Objects in different time points are connected by group ID.

## Object export
You can export objects as meshes (to process them further in graphical programs such as Blender) or as masks. To export measurements for objects, go to [Results Viewer](../results-viewer/index.md).

1. Go to the bottom of **Model** tab. 
2. Press **Export objects** button. 
3. A dialog window appears. Select which types of objects you want to export for which time points, and how.
