# Register objects across time points

Use registration to match individual dendrite models between time points.

!!! info "Before you start"
    **Prerequisites:**

    - Primary 3D model created for all time points.
    - Time drift corrected.

    **UI location:**

    - Main app: **Model** tab, **Full** subtab, **Object list** section.

## Steps

1. Open **Object list**.
2. Review the list of individual dendrite models. Each spatially separated object appears as a separate item.
3. Press **Register**.
4. Check registration by selecting an object in the list or visualization window and moving through time points.
5. Confirm that the object keeps the same group ID, shown in brackets next to the model.
6. If registration is wrong, increase the recognition limit next to **Register**.
7. Press **Register** again to apply the changed limit.
