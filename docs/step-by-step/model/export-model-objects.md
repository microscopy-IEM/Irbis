# Export model objects

Export model objects when you need meshes or masks for processing outside Irbis. To export measurement tables, use [ResultsViewer](../results-viewer/index.md).

!!! info "Before you start"
    **Prerequisites:**

    - 3D model created.

    **UI location:**

    - Main app: **Model** tab.
    - Bottom of the **Model** tab: **Export objects** button.

## Export meshes or masks

1. Go to the bottom of the **Model** tab.
2. Press **Export objects**.
3. In the export dialog, select which object types to export.
4. Select which time points to export.
5. Select the export format.
6. Confirm the export.

Meshes can be used in external 3D software such as Blender. Masks can be used for downstream image or volume analysis.

## Related

- Use [Select and manipulate model objects](object-list-context-menu.md) before export if objects need correction.
- Use [ResultsViewer](../results-viewer/index.md) to inspect and export measurement tables.
