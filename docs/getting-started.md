# Getting started

Start here if you are new to Irbis.

Irbis documentation is organized around two kinds of guidance:

- **Tutorials** introduce Irbis through complete workflows. Use them when you are learning the app or want to see how the basic functionality fits together.
- **Step-by-step guides** explain individual tasks. Use them when you already work with Irbis and need help with a specific operation.

## First steps

1. [Install Irbis](getting-started/installation.md).
2. Open Irbis.
3. Follow the basic tutorial: [Segment dendritic spines from a single time point](tutorials/segment-spines.md).

The basic tutorial introduces the core Irbis workflow: importing microscopy data, viewing planes, creating a 3D model, tracing a dendrite, separating spines, calculating features, and saving the project.

## After the basic tutorial

- Use the [step-by-step guides](step-by-step/index.md) to look up individual tasks.
- Use [ResultsViewer](step-by-step/results-viewer/index.md) to explore generated tables and plots.
- Use the [reference](reference/index.md) pages when you need details about Irbis files, tables, or parameters.
