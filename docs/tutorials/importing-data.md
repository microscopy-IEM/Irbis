# Tutorial: importing data

Use this tutorial when you only need to get data into Irbis and save the project.

1. [Load data](../step-by-step/data-import/load-data.md).
2. If you loaded planes, check [View raw planes data](../step-by-step/planes/view-raw-data.md).
3. If you loaded TrackMate XML files, check [Import tracks](../step-by-step/tracks/import-tracks.md) and [View tracks](../step-by-step/tracks/view-tracks.md).
4. Save the project with [Export processed data as an .irbis file](../step-by-step/data-import/save-irbis.md).
