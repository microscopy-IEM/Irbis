# Tutorial: segment dendritic spines from a single time point

This is the main end-to-end flow for structural microscopy data.

## Flow

1. [Load](../step-by-step/data-import/load-data.md) and [view](../step-by-step/planes/view-raw-data.md) structural data.
2. Optional: [Align planes across time points](../step-by-step/planes/align-planes.md), [Crop planes](../step-by-step/planes/crop-planes.md), or [Preprocess planes](../step-by-step/planes/preprocess-data.md).
3. [Create a new model](../step-by-step/model/create-model.md).
4. [Create a primary 3D model](../step-by-step/model/reconstruct-primary-model.md).
5. [Trace a dendrite](../step-by-step/model/track-dendrite.md).
6. [Generate the dendritic shaft](../step-by-step/model/generate-shaft.md).
7. [Separate spines from the shaft](../step-by-step/model/separate-spines.md).
8. [Save the project as an .irbis file](../step-by-step/data-import/save-irbis.md).
