# Tutorial: import, reconstruct, track, separate, export

This is the main end-to-end flow for structural microscopy data.

## Flow

1. [Load data](../step-by-step/data-import/load-data.md).
2. [View raw planes data](../step-by-step/planes/view-raw-data.md) and verify pixel size and z-step.
3. Optional: [Align planes across time points](../step-by-step/planes/align-planes.md), [Crop planes](../step-by-step/planes/crop-planes.md), or [Preprocess planes](../step-by-step/planes/preprocess-data.md).
4. [Create a new model](../step-by-step/model/create-model.md).
5. [Create a primary 3D model](../step-by-step/model/reconstruct-primary-model.md).
6. [Detect drift and correct it](../step-by-step/model/drift-correction.md).
7. [Register objects across time points](../step-by-step/model/register-objects.md).
8. [Track a dendrite](../step-by-step/model/track-dendrite.md).
9. [Generate the dendritic shaft](../step-by-step/model/generate-shaft.md).
10. [Separate spines from the shaft](../step-by-step/model/separate-spines.md).
11. [Select objects and export results](../step-by-step/model/select-export-objects.md).
12. [Save the project as an .irbis file](../step-by-step/data-import/save-irbis.md).
