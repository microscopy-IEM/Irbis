# Tutorial flows

Tutorials introduce Irbis through complete guided workflows. Use them when you are learning the app, teaching someone the basic functionality, or checking the recommended order of operations.

For individual tasks, use the [step-by-step guides](../step-by-step/index.md).

## Available tutorials

| Tutorial | Use it to learn | Main output |
| --- | --- | --- |
| [Segment dendritic spines from a single time point](segment-spines.md) | The basic Irbis workflow: import data, view planes, create a 3D model, trace a dendrite, separate spines, calculate features, and save the project. | A saved `.irbis` project with segmented spines and calculated features. |
| [Compare datasets in ResultsViewer](compare-results-viewer-datasets.md) | Batch loading, categorization, filtering, temporal plots, and export in ResultsViewer. | A combined ResultsViewer dataset and exported plots. |
