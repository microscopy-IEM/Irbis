    Track a dendrite

    Before you start

    Prerequisites:

    • Primary 3D model created for all time points.
    • Time drift corrected.
    • Primary 3D model registered in time.

    UI location:

    • Main app: Model tab, Dendrite subtab, Dendrite tracking section.

    Steps

    1. To track the dendrite for every time point, check All time points.
    2. Press Track dendrite.
    3. Select the object to track by clicking it.
    4. When planes data appear, left-click one end of the dendrite.
    5. Left-click the other end of the dendrite.
    6. If tracking fails at a time point, select the start and end points again when prompted.
    7. To exit selection, press Esc.

    Next steps
